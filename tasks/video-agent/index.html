    Learning evidence and limitations
    


    

    Keep the Mac unlocked. The agent stops on lock, foreground changes or an unconfirmed step. Model-observed completion is not independent verification. After observed completion, the agent saves a new .blend file through the GUI. For supported cube-and-Bevel workflows, final-state targets are derived from the original source before execution. A separate read-only Blender process measures the saved file against those targets. Other workflows remain unverified. The old fixed 0.22 m / Edges checker applies only to legacy reference runs.
